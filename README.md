# 하루한문장

한국 시간으로 매일 한 문장이 앱 첫 화면과 위젯에 함께 도착합니다. 원하는 날에는 두 편을 더 읽을 수 있습니다. 위젯을 누르면 표시 중인 문장의 작성자, 평가와 댓글이 열립니다.

## 바로 실행하기

저장소 루트에서 Python 3.11 이상으로 커뮤니티 서버를 실행하세요.

```sh
python3 server/server.py
```

브라우저에서 [하루한문장 열기](http://127.0.0.1:8000). 첫 실행에 SQLite 데이터베이스와 기본 문구 31편이 준비됩니다. 두 개의 브라우저 프로필로 서로 다른 계정의 제출과 반응을 시험할 수 있습니다.

| 플랫폼 | 시작 방법 |
| --- | --- |
| iPhone | Mac에서 `ios/Haru.xcodeproj`를 열고 Haru 스킴을 실행합니다. 잠금 화면의 사용자화 메뉴에서 하루한문장 위젯을 추가합니다. [iOS 빌드와 위젯 설정](ios/README.md) |
| Android | Android SDK를 설정하고 저장소 루트에서 `./android/gradlew -p android :app:assembleDebug`를 실행합니다. 홈 화면의 위젯 선택기에서 추가합니다. 잠금 화면 지원은 기기에 따라 다릅니다. [Android 실행 안내](android/README.md) |

서버 주소를 설정하기 전에도 모바일 앱과 위젯에서 기본 문장을 읽을 수 있습니다. 개발 중에는 iPhone 시뮬레이터에서 `http://localhost:8000`, Android 에뮬레이터의 디버그 앱에서 `http://10.0.2.2:8000`으로 연결합니다. 여러 기기에서 함께 쓰려면 같은 HTTPS 서버 주소를 사용합니다. 배포 빌드에 기본 주소를 넣는 방법은 각 플랫폼 안내에 있습니다.

## 문장을 고르고 나누는 방식

- 처음에는 이 앱을 위해 작성한 문장과 확언을 보여줍니다. 회원 제출 문장은 제출 다음 날부터 편성 후보가 됩니다. 기본 문장과 회원 문장이 모두 있으면 대표 문장에 번갈아 등장합니다.
- 문장은 한 줄, 최대 48자로 제한합니다. 회원 한 명이 한국 시간으로 하루 한 편을 제출할 수 있습니다. 댓글은 최대 400자이며 문장에 직접 남깁니다.
- 문장과 댓글에 각각 엄지 올림·내림을 표시합니다. 다시 누르면 취소되고, 반대쪽을 누르면 선택이 바뀝니다. 댓글은 공감순 또는 최신순으로 볼 수 있고, 순추천이 양수인 최상위 댓글에 BEST가 붙습니다.
- 웹 화면에서 책갈피를 누르면 문장 ID를 해당 기기에 보관합니다. 문장 링크를 복사하면 다른 사람도 같은 문장을 열 수 있습니다.
- 운영자는 신고 사유와 반응 수를 보고 문장을 숨길 수 있습니다. 관리 권한 부여, 세션, 데이터 보관과 HTTPS 운영 방법은 [서버 안내](server/README.md)에 있습니다.
- 초기 버전은 무료로 제공하는 기준으로 구현했습니다. 문장 편성은 유료 여부와 관계없이 날짜에 따라 결정됩니다.

## 서버 검증

```sh
python3 -m unittest discover -s server
```

## Sites 커뮤니티

Sites 빌드는 Python 3으로 `python3 sites/build.py`를 실행해 생성합니다. Node 24에서 `node sites/smoke.mjs`로 Worker API를 검증할 수 있습니다. Sites 운영 데이터는 `DB` D1 바인딩에 저장됩니다.

첫 관리자 설정에는 Sites 런타임 시크릿 `HARU_ADMIN_KEY`가 필요합니다. 원하는 계정으로 가입 후 로그인하고 관리자 초기 설정 화면에 동일한 키를 입력합니다. 초기 관리자가 생성되면 시크릿을 삭제할 수 있습니다.
